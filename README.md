# 🌿 CalmStream

A minimal website for endlessly streaming calming nature videos.

Built to be distraction-free — just press play and relax.

---

## ✨ Features

- Fullscreen video experience (desktop + mobile)
- Endless looping playlist of videos
- Automatic next-video preloading (no buffering pauses)
- Clean, minimal UI
- Mobile-friendly with proper video framing
- No accounts, no clutter — just content
